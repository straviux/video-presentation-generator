# Birthday Template: config-driven HyperFrames composition

The first real template for the Video Presentation Generator. It renders a
complete birthday video (1280x720, 30fps, about 1 minute) from a single
`config.json`. No hand-editing HTML per person.

## How it works

```
config.json  --(node generate.mjs)-->  index.html  --(hyperframes render)-->  renders/birthday-sample.mp4
```

- `config.json` is the only file you edit per video: celebrant name and role,
  the photo list with captions, which photos go into the collage, the two
  greeting messages with signers, the closing line, and the from line.
- `generate.mjs` reads the config, builds every scene, computes the timeline,
  and writes the final composition to `index.html`. The generated HTML carries
  a "Generated by generate.mjs" comment; edit the config or the generator,
  never the generated file.
- GSAP is loaded from a local copy at `assets/gsap.min.js`, so renders work
  offline with no CDN dependency.

## Scene timing

| Scene | Time | Duration | What happens |
|---|---|---|---|
| Title card | 0:00-0:05 | 5s | "Happy Birthday, [Name]!" with name, role, and from line, staggered entrance |
| Photo montage | 0:05-0:40 | 7 x 5s = 35s | One photo per beat, slow Ken Burns zoom, caption fades in, gentle fade between photos |
| Photo collage | 0:40-0:46 | 6s | 3 photos in polaroid frames pop in one by one under a heading |
| Message card 1 | 0:46-0:52 | 6s | Greeting text on a card, signer line fades in |
| Message card 2 | 0:52-0:58 | 6s | Second greeting and signer |
| Closing card | 0:58-1:06 | 8s | Closing line and sign-off, held to the end |
| **Total** | | **66s** | |

Sample content: a birthday video for Nur-Aina Ibrahim, Program Manager, with
messages from the YSE Family. Sample photos are seeded downloads from
picsum.photos (1280x720), stored in `assets/photos/photo-1.jpg` to
`photo-7.jpg`.

## Commands

Run from this folder. The `TMPDIR` and frames-cache settings are required on
this VM: `/tmp` has almost no free space and a default render aborts with
"Low disk space" (see `../SETUP.md`).

```bash
cd ~/workspace/video-presentation-generator/render-engine/birthday-template

# 1. Generate the composition from config.json
node generate.mjs

# 2. Validate (lint, runtime, layout, motion, contrast)
TMPDIR=$HOME/workspace/video-presentation-generator/render-engine/.tmp \
HYPERFRAMES_EXTRACT_CACHE_DIR=$HOME/workspace/video-presentation-generator/render-engine/.frames-cache \
../node_modules/.bin/hyperframes check

# 3. Render the MP4
TMPDIR=$HOME/workspace/video-presentation-generator/render-engine/.tmp \
HYPERFRAMES_EXTRACT_CACHE_DIR=$HOME/workspace/video-presentation-generator/render-engine/.frames-cache \
../node_modules/.bin/hyperframes render . -o renders/birthday-sample.mp4 --frames-cache-dir ../.frames-cache

# 4. Verify the output
ffprobe renders/birthday-sample.mp4
```

## Make a video for another person

1. Replace the files in `assets/photos/` with the new person's photos
   (1280x720 or larger works; the composition crops to fill).
2. Edit `config.json`:
   - `celebrantName`, `celebrantShortName`, `role`, `occasion`
   - `photos`: one entry per montage photo, `file` path plus `caption`
   - `collage.photoIndexes`: which photos (zero-based positions in the
     `photos` list) appear in the collage; exactly 3
   - `messages`: exactly 2 entries, `text` plus `signedBy`
   - `closingLine`, `closingSignOff`, `fromLine`
3. Re-run `node generate.mjs`, then the render command above.
4. The new MP4 lands wherever you point `-o`; rename it per person, for
   example `renders/birthday-juan.mp4`.

Note: changing the number of photos or messages changes the total duration,
since every photo gets 5s and every message card 6s. The generator prints
the new total when it runs.

## Known gaps (v1)

- **No music or audio track.** The render is silent. Adding a royalty-free
  background track (and an audio fade) is the top v2 item.
- **Birthday template only.** Appreciation, Awards, and Retirement templates
  from the prototype are not built yet; they would follow this same
  config-to-composition pattern.
- No automated photo cropping control: photos are center-cropped to fill
  16:9 by the composition CSS.
- Sample photos are generic picsum images, not real celebrant photos.
